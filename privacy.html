Privacy Policy

This policy explains how yt-relay ("the app") handles data. The app is operated by the owner of the Buka Fakta channel for their own use only.

Data the app accesses

  • Through Google OAuth, the owner authorizes the app to use the YouTube Data API with the scopes youtube.upload (upload videos) and youtube.readonly (confirm the channel ID and read view counts of the owner's own videos).
  • The app only accesses the owner's own YouTube channel. It does not access, collect or process data of any other user.

How data is stored

  • The OAuth access/refresh token is stored only on the owner's private server and is never shared with anyone.
  • Video statistics are stored on the same server only to measure the performance of the owner's own videos.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After revocation, the stored token stops working and is deleted.
